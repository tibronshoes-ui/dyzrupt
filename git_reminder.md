# Instrucciones
- Cuando el usuario finalice una tarea, corrección de código o implementación de UI, debes recordarle obligatoriamente con el siguiente mensaje:
"¡Excelente avance, colega! Recuerda blindar tu progreso en GitHub: ejecuta `git add .`, `git commit -m 'descripción del cambio'` y `git push`."
